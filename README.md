# Midterm JavaScript Source Files

JavaScript activities by Russell Junio, organized by lesson.

## Contents

| Folder | Source file | Topics |
| --- | --- | --- |
| Lesson1 | Week3_Lesson1_Activity1.js | Student grades, loops, conditions, and statistics |
| Lesson1 | Week3_Lesson1_Activity2.js | Student class, methods, averages, and letter grades |
| Lesson2 | Junio_AdrianRussell_ArrayExcercise3.js | Array operations, filtering, sorting, and two-dimensional arrays |
| Lesson3 | Junio_AdrianRussell_CC104_W6.js | Stack, queue, priority queue, and linked list |

## Running the programs

With Node.js installed, open a terminal in this repository and run a file individually:

```bash
node Lesson1/Week3_Lesson1_Activity1.js
node Lesson1/Week3_Lesson1_Activity2.js
node Lesson2/Junio_AdrianRussell_ArrayExcercise3.js
node Lesson3/Junio_AdrianRussell_CC104_W6.js
```

Each program prints its results in the terminal.

## Git workflow demonstration

The repository keeps the original commits and adds separate commits for the three lesson folders. The `documentation` branch adds the lesson guide and is merged into `main` with a merge commit.

A second local copy was created with `git clone`. This final README update was committed in that copy and can be synchronized to the original folder with `git pull origin main`.

The final submission commit is named `midterm_sourcefiles_demo`.
